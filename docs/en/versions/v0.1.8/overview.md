# Agent Evidence v0.1.8

Agent Evidence v0.1.8 is a patch release that aligns evidence, replay, review, redaction, and export records with the Agent Runtime profile spine.

## Highlights

- Adds runtime profile test cases for runtime ids, tool failures, permission denial, routing, evidence packs, replay, review, known gaps, redaction, and export manifests.
- Aligns interoperability guidance with Agent Runtime events, thread read models, and task snapshots.
- Adds optional runtime profile correlation fields to event and evidence pack schemas.
- Refreshes README, navigation, LLM entrypoints, release notes, package metadata, and version snapshots for v0.1.8.
