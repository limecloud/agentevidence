# Telemetry correlation

Telemetry 解释 operationally 发生了什么。Evidence 解释为什么 outcome 可以被信任。Agent Evidence 应引用 telemetry，而不是替代 telemetry。

## Required correlation fields

- `trace_id`
- `span_id`
- `span_kind` when known
- `event_id` or log id when known
- 可用时的 `runtime_id`、`session_id`、`thread_id`、`turn_id`、`task_id`、`run_id`、`tool_call_id`、`artifact_id`
- traces 未嵌入时的 exporter 或 backend reference

## Rules

- 不要把 raw traces 复制进每个 evidence pack。
- 可用时保留 W3C trace context ids。
- 可用时保留 OpenTelemetry GenAI operation names。
- Telemetry 缺失时标记为 `unavailable` 或 `not_collected`，不要推断为 success。
- 将 evidence facts 连接到最小有用 span 或 event。
- 将 tool arguments 与 results 视为可能 sensitive。

## Common joins

| Evidence fact | Telemetry join |
| --- | --- |
| Claim derived from tool result | `tool_call_id`、tool span、result ref。 |
| Claim derived from retrieval | retrieval span、query id、source ids。 |
| Artifact generated by a model | model span、artifact id、version id。 |
| Verification check | check activity id、span id、issue refs。 |
| Export | export activity id、file hashes、pack id。 |
