# v0.1.0 specification snapshot

v0.1.0 requires compatible implementations to expose evidence pack identity, claim map semantics, source map semantics, provenance chains, verification results, review verdicts, replay cases, redaction records, telemetry correlation, evidence events, and export manifests when those facts exist.
