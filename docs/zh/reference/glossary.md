# 术语表

| Term | 含义 |
| --- | --- |
| Evidence pack | 证据事实的可移植容器。 |
| Claim | 需要支撑的断言、决策、建议、字段或 artifact section。 |
| Source ref | 指向 support、contradiction、background 或 provenance material 的引用。 |
| Support edge | Claim 与支撑或挑战它的 evidence 之间的关系。 |
| Claim map | 将 claims 连接到 sources 与 verification facts 的 graph。 |
| Source map | selected、omitted、stale、contradicted、unavailable sources 的目录。 |
| Provenance chain | entities、activities、agents 的生产图。 |
| Verification | 基于 evidence 的自动或人工检查。 |
| Review | human、policy 或 automated reviewer 的 verdict。 |
| Replay case | 重建说明与 missing-fact record。 |
| Redaction | 对敏感 evidence 的显式转换或隐藏。 |
| Export manifest | 导出 pack 的 file、schema、hash、access 与 completeness record。 |
| Completeness | 按 category 声明 facts 是 present、partial、missing 还是 not collected。 |
