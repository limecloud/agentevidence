# Agent Evidence v0.1.0

Agent Evidence v0.1.0 定义 Agent 工作的第一版可移植证据标准：claim maps、source maps、provenance chains、verification results、review verdicts、replay cases、redaction records、telemetry correlation、events、schemas 与 export manifests。

## Highlights

- 定义 Evidence Pack 作为 audit 与 review facts 的可移植容器。
- 增加比简单 citations 更细的 claim-to-source grounding。
- 增加 source omission、contradiction、freshness 与 trust records。
- 增加 tools、models、retrieval、artifacts、humans、peer agents 与 runtimes 的 provenance chains。
- 将 verification 与 review 定义为不同 facts。
- 增加 replay、redaction、privacy、telemetry、event 与 export guidance。
- 增加 public JSON Schemas 与 LLM-friendly documentation entrypoints。
