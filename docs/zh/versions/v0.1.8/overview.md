# Agent Evidence v0.1.8

Agent Evidence v0.1.8 是 patch release，用于把 evidence、replay、review、redaction 与 export records 对齐 Agent Runtime profile spine。

## 重点

- 新增 runtime profile 测试用例，覆盖 runtime ids、tool failures、permission denial、routing、evidence packs、replay、review、known gaps、redaction 与 export manifests。
- 将互操作指南对齐 Agent Runtime events、thread read models 与 task snapshots。
- 在 event 与 evidence pack schemas 中加入可选 runtime profile correlation 字段。
- 刷新 README、导航、LLM entrypoints、release notes、package metadata 与 v0.1.8 版本快照。
